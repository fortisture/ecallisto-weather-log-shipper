A station is judged up or down by what actually arrived, not by a ping. Each stream has an expected cadence; if data stops showing up for several times that interval, the stream is late, and well past that it is down. The instrument stream is the one that decides the station's overall state — weather still flowing while CALLISTO is silent is exactly the failure this page exists to catch.
